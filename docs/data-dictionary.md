# 数据字典

| 对象 | 用途 | 必填审计字段 |
|---|---|---|
| Report | 原始报告登记 | 文件名、哈希、期间、存储路径 |
| FinancialFact | 可计算的财务事实 | 科目、数值、单位、口径、页码、原文 |
| MetricCalculation | 确定性指标计算 | 公式、输入事实 ID、结果、期间 |
| AnomalySignal | 规则触发的风险提示 | 规则 ID、事实 ID、解释、核查建议 |
| EvidenceLink | 报告证据定位 | 事实 ID、文件、页码、原文摘录 |
| AgentRun | 一次完整任务 | run_id、输入报告、模型、Git commit、输出路径 |
| ExtractionBatch | 两份报告的一次抽取与人工核验 | 公司、连续年度、事实列表、问题、核验状态 |
| FactRevision | 人工修改记录 | 原值、新值、原单位、新单位、原因、时间 |

财务事实同时保留原始数值、原始单位和标准化人民币元金额。抽取状态、已核验状态和暂缺状态必须区分；暂缺数据不进入计算。所有风险提示均为待核查信号，不构成财务造假认定或投资建议。
