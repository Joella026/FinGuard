# FinGuard

面向财务报告的可审计分析工作台。FinGuard 先从 PDF 提取财务事实，由用户核对关键数据，再通过确定性程序计算指标、识别待核查信号，并将结果回链到公式、输入数据、报告页码和原文。股票自动查询仅覆盖 A 股；手动上传不要求上市公司身份。

## 初赛版本能力

- 输入六位 A 股股票代码，检索巨潮资讯公开披露的年报、半年报、一季报和三季报，查看原文或保存 PDF 到本地。
- 股票查询后可对任意一份完整年报、半年报或季报启动核验，也可一键选取最近连续两年的完整年报做同比分析。手动上传不要求 A 股代码；填写主体名称、报告币种和期间后，可核验上市或非上市公司的 PDF 财务报告。
- 核验营业收入、归母净利润、扣非净利润、经营现金流、应收账款和存货。
- 计算年度变化、净利率、经营现金流与净利润比、非经常性损益贡献率。
- 识别利润与现金流背离、应收异常、存货异常和非经常性损益依赖。
- 区分“未触发异常”和“数据不足无法判断”。
- 导出 HTML 报告和完整 JSON；可选使用模型生成审慎摘要。

美的集团和贵州茅台的 2024、2025 年报仍保存在本机，供股票查询和离线回退使用；24 项核心事实的标准答案、来源和 SHA-256 记录在 `data/benchmark/real_cases.json`。真实案例需复核其页码、单位和判断边界后再用于答辩。

## Windows 本地启动

首次安装：

~~~powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup.ps1 -Dev
~~~

以后启动：

~~~powershell
.\scripts\start.ps1
~~~

打开 http://127.0.0.1:8000。API 文档位于 http://127.0.0.1:8000/docs。

左侧导航只有“新建分析”和“历史记录”。新建分析顶部在“股票查询并核验”和“手动上传财报”之间切换。单份报告可核验并计算本期比率；跨年变化率和三项同比信号需要同一家公司连续两份完整年报，缺少对比期时显示“无法判断”。核验任务会进入历史记录；结果页按“概览、分析过程、异常信号、原文证据”逐层展示，并可返回查看核验数据。规则步骤、数值、阈值、差额与证据链接由后端统一生成，HTML 和 JSON 导出使用同一判断口径。网站与 API 均由同一个本地地址提供，关闭运行脚本的窗口后网站会停止。

手动上传支持三位币种代码，例如 CNY、HKD、USD；两份报告对比必须使用同一币种，不做汇率换算。自动抽取目前主要面向中文 PDF 中的六项预设指标；其他版式可在核验页人工补充数值、原始单位、页码和摘录。缺失指标可标记暂缺，依赖它的计算或规则会显示“无法判断”。扫描版或加密 PDF 可能无法自动读出文字，不能仅凭上传就生成有效结论。

公告检索使用巨潮资讯网站的公开查询端点，需要本机能够访问 `www.cninfo.com.cn` 和 `static.cninfo.com.cn`。这不是已签约的金融终端或正式授权 API，网站端点可能调整。连接失败时，搜索会明确提示，并仅展示本机已登记的报告。当前界面只提供 A 股查询；自动下载的报告会记录公告 ID、原文链接和 SHA-256。

如需重新登记真实案例，先确认 `data/benchmark/real_cases.json` 中列出的四份 PDF 均位于指定路径，再运行：

~~~powershell
.\.venv\Scripts\python.exe scripts\prepare_real_cases.py
~~~

脚本会核对四份文件的哈希、抽取并逐项比对 24 个标准数值与证据页码，复用已有登记记录。原始 PDF 被 Git 忽略；换电脑时需根据标准答案文件中的来源链接补齐 2024 年报，并复制团队提供的 2025 年报。

开发前端时，可以分别运行后端和 Vite：

~~~powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload
cd frontend
npm run dev
~~~

前端开发地址为 http://127.0.0.1:5173，请求会代理到本地后端。

## 验证

~~~powershell
.\.venv\Scripts\python.exe -m pytest backend/tests -q
cd frontend
npm run build
~~~

## 目录

- frontend：React、TypeScript 和 Ant Design 网站。
- backend/app/main.py：FastAPI 接口与静态网站入口。
- backend/app/services：抽取批次、人工核验、运行编排和存储。
- backend/app/tools：PDF 解析、取数、计算、规则和审计日志。
- data：本地报告、报告登记和核验批次。
- runs：每次分析的 JSON、HTML 和审计日志。

原始财报、环境变量、运行日志及数据库均由 Git 忽略。不要提交 API Key、原始报告或含个人信息的材料。
